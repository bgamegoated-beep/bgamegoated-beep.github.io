BounceFactory

▶ This application uses YouTube API Services

BounceFactory is a personal desktop tool that publishes short, original physics and math animations (bouncing balls, Galton boards, color battles) that I create myself to my own YouTube channel BounceFactory, and reads the statistics of my own videos.

It uses the YouTube Data API to upload videos to my channel and to read views, likes and comments of my own videos. It is used only by its owner and is not offered to other users.
