Privacy Policy – BounceFactory

Last updated: November 9, 2026

▶ This application uses YouTube API Services

1. Who we are

BounceFactory is a personal desktop tool used only by the owner of the YouTube channel "BounceFactory" to publish his own videos and read their statistics.

2. YouTube API Services

BounceFactory uses YouTube API Services. By using BounceFactory you agree to be bound by the YouTube Terms of Service. Please also see the Google Privacy Policy.

3. Information we access, collect and use

With the explicit OAuth authorization of the channel owner, BounceFactory accesses through the YouTube API Services:

  • the authorized channel's basic information (channel name, subscriber count);
  • the videos uploaded by BounceFactory to that channel and their public statistics (views, likes, comments counts);
  • comments posted on those videos, only to display them to the channel owner so he can reply.

This information is used only to upload the owner's videos and to show him a local statistics dashboard. No information about other YouTube users is collected beyond the public text of comments on the owner's own videos.

4. Storage

The OAuth token and the statistics are stored only on the owner's computer, in local files. Nothing is stored on a server.

5. Sharing

No information is shared with, sold to, or disclosed to any third party, and none is used for advertising.

6. Cookies

BounceFactory does not use cookies or similar technologies on user devices.

7. Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. Deleting the local files of the application removes all stored data. Stored statistics are refreshed or deleted at least every 30 days. For any deletion request, contact bgame.goated@gmail.com.
